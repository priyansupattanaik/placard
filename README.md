# PLACARD

Cross-platform wallpaper engine (Windows, macOS, Linux) written entirely in Rust, with a Rust-built landing page.

"The wall is the work. The interface is the label."

## Features
- **Curated Discover**: High-resolution wallpapers from verified open-access sources (The Met, Art Institute of Chicago, Wallhaven, NASA APOD, Pexels, Pixabay, Local Import).
- **Museum Placard**: Full artist, year, license, and source attribution on every item.
- **Adaptive Accent**: System accents dynamically sampled from the applied wallpaper using Oklab/OKLCH color theory.
- **Precision Scheduler**: Rotate per display on intervals, wake, or login.
- **Privacy First**: Zero telemetry, zero accounts, keys kept strictly in the OS keychain.
